# Plataforma Web para ONGs

## 📖 Sobre o Projeto
Projeto acadêmico desenvolvido para a disciplina de Desenvolvimento Front-end, focado em criar uma plataforma web completa para Organizações Não Governamentais.

## 🎯 Objetivo
Desenvolver uma solução digital que permita às ONGs gerenciar atividades, divulgar projetos, captar recursos e engajar voluntários.

## 🚀 Funcionalidades Implementadas
- *Página institucional* com informações da organização
- *Portal de projetos* sociais e oportunidades de voluntariado
- *Sistema de cadastro* para voluntários e doadores
- *Formulários complexos* com validação e máscaras

## 🛠 Tecnologias Utilizadas
- HTML5 Semântico
- CSS3
- JavaScript Vanilla

## 📁 Estrutura do Projeto
